# 14. Check CSS Cropping

This is important.

If the video uses:

```css
object-fit: cover;
```

the visible camera preview may be CROPPED compared with the raw camera frame.

Example:

```text
RAW CAMERA

┌───────────────────────────────┐
│                               │
└───────────────────────────────┘

MOBILE DISPLAY

      ┌─────────────┐
      │ visible     │
      │ cropped     │
      │ area        │
      └─────────────┘
```

If target projection uses raw-frame coordinates while overlay uses the cropped display, EVERYTHING can appear misaligned.

Calculate the actual `object-fit: cover` transformation:

```text
scale
cropX
cropY
displayWidth
displayHeight
```

and use it in `cameraToDisplay()`.

This is a HIGH-PRIORITY check.
